# Munawwar Ali - Web Portfolio 🚀

A high-performance, visually stunning React portfolio tailored for a Full Stack Developer. It features a fully animated, responsive Single Page Application (SPA) designed to showcase professional experience, projects, and skills.

## 🌟 Features
- **Modern UI/UX**: Premium glassmorphism design with a tailored dark theme and vibrant accent colors.
- **Physics-Based Animations**: Utilizes Framer Motion for advanced scroll animations, layout transitions, and interactive hover effects.
- **Responsive Design**: Flawlessly adapts to mobile phones, tablets, and desktop screens.
- **Custom Interactions**: Includes a custom-animated cursor and an interactive particle background algorithm.
- **Performance Optimized**: Built with Vite and React for ultra-fast Development Environment and production builds.

## 🛠️ Technologies Used
- **Frontend Framework**: [React 19](https://react.dev/)
- **Build Tool**: [Vite 8](https://vitejs.dev/)
- **Animations**: [Framer Motion 12](https://www.framer.com/motion/)
- **Icons**: [React Icons](https://react-icons.github.io/react-icons/)
- **Styling**: Vanilla CSS (Extensive CSS Variables, Flexbox, Grid, Glassmorphism Effects)

## 🚀 Getting Started

Follow these steps to run the portfolio locally on your machine:

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed.

### Installation

1. **Navigate to the project directory**:
   ```bash
   cd munawwar-react-portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```

4. **Open your browser** and visit `http://localhost:5173` to view the application in action.

## 🏗️ Building for Production

To create an optimized, production-ready build:
```bash
npm run build
```
The bundled static files will be generated in the `dist` folder, which can be deployed to Vercel, Netlify, GitHub Pages, or any standard static hosting platform.
